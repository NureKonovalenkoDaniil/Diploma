# РЕФЕРАТ

**Відомості про обсяг звіту:** звіт містить ___ сторінок, ___ частин, ___ рисунків, ___ таблиць, ___ додатків, ___ джерел за переліком посилань.

**Ключові слова:** BACKEND, DOTNET, ESP32, FRONTEND, IOT, ЖИТТЄВИЙ ЦИКЛ, ІНЦИДЕНТИ, KOTLIN, МЕДИКАМЕНТИ, МОНІТОРИНГ, MULTI-TENANCY, REACT, РОЗПОДІЛЕНА СИСТЕМА, СЕНСОРИ, СПОВІЩЕННЯ, TYPESCRIPT, УМОВИ ЗБЕРІГАННЯ.

**Об'єкт дослідження:** процеси управління життєвим циклом медичних препаратів та моніторингу умов їх зберігання в розподілених інформаційних системах.

**Ціль роботи:** розробка розподіленої інформаційної системи управління життєвим циклом та безпекою зберігання медичних препаратів з автоматичним IoT-моніторингом, multi-tenancy архітектурою та рольовим контролем доступу.

**Методи дослідження та апаратура:** для розробки backend використано ASP.NET Core 8.0 з Entity Framework Core та JWT-автентифікацією; для frontend — React 19 з TypeScript та shadcn/ui компонентами; для мобільного застосунку — Kotlin з Retrofit та Coroutines; для IoT-моніторингу — мікроконтролер ESP32 з датчиком DHT22. Тестування виконано за допомогою xUnit, Moq, FluentAssertions для backend та Vitest з React Testing Library для frontend.

**Результати та їхня новизна:** створено повнофункціональну розподілену систему з multi-tenancy архітектурою, що забезпечує ізоляцію даних між організаціями. Реалізовано автоматичне відстеження життєвого циклу препаратів через події типу Received, Moved, Issued, Disposed, Expired. Впроваджено систему автоматичного виявлення та реєстрації інцидентів порушення умов зберігання з debounce-логікою та auto-resolve механізмом. Розроблено чотирирівневу рольову модель (Administrator, Manager, User, Device) з динамічною фільтрацією даних на рівні сервісів. Система складається з 9 контролерів, 8 сервісів, 14 моделей даних та охоплює повний цикл від надходження препарату до його утилізації.

**Основні характеристики:** backend API надає 34 ендпоінти для управління препаратами, локаціями зберігання, IoT-пристроями, інцидентами, сповіщеннями та аудитом. Frontend SPA реалізує 14 сторінок з адаптивним дизайном, підтримкою темної теми та real-time polling сповіщень. Мобільний застосунок забезпечує повний функціонал для професійного та домашнього використання з підтримкою MVVM архітектури. IoT-компонент виконує зчитування температури та вологості кожні 10 секунд з автоматичною відправкою даних на backend через HTTP POST. Фонові служби виконують моніторинг умов зберігання (інтервал 60 секунд) та перевірку термінів придатності (щоденно) з автоматичним створенням сповіщень.

**Інформація щодо впровадження:** система розроблена як дипломний проект та готова до розгортання в production середовищі. Архітектура підтримує горизонтальне масштабування через multi-tenancy модель. Передбачено можливість інтеграції з існуючими медичними інформаційними системами через REST API.

**Рекомендації щодо використання результатів:** система може застосовуватись в аптеках для контролю запасів та умов зберігання, в медичних закладах для управління медикаментами та відстеження їх використання, в приватних домогосподарствах як домашня аптечка з нагадуваннями про терміни придатності. Рекомендується розгортання в Docker-контейнерах з PostgreSQL для production та використання HTTPS для захисту даних при передачі.

**Економічна ефективність:** впровадження системи дозволяє скоротити втрати від прострочених медикаментів через автоматичні сповіщення про терміни придатності, зменшити ризики порушення умов зберігання через real-time моніторинг, оптимізувати управління запасами через відстеження життєвого циклу та автоматичні рекомендації щодо поповнення. Multi-tenancy архітектура знижує витрати на інфраструктуру при обслуговуванні кількох організацій.

**Висновки:** розроблена система демонструє практичне застосування сучасних технологій розподілених систем, IoT-інтеграції, multi-tenancy архітектури та рольового контролю доступу. Реалізовано повний цикл розробки від проєктування до тестування з покриттям 56 автоматизованими тестами (36 backend + 20 frontend). Система готова до захисту та подальшого розвитку в напрямку CI/CD автоматизації, Docker-контейнеризації та розширення IoT-функціоналу.
